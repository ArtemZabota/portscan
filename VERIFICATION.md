# Проверка реализации

Дата: 28 октября 2026 года.

Среда выполнения: Windows/amd64, **Go 1.25.5**, CGO и GCC включены. Версия Go 1.25.5 загружена отдельно от установленной в системе версии; все перечисленные проверки выполнялись ею.

| Проверка | Результат |
| --- | --- |
| `go test -race ./...` | PASS; гонки данных не обнаружены. |
| `go vet ./...` | PASS, диагностик нет. |
| `gofmt -l .` | Вывод пуст, форматирование соответствует gofmt. |
| Компиляция тестового бинарника для Linux/amd64, `CGO_ENABLED=0` | PASS. Linux-тесты не запускались. |
| IPv4 TCP Connect, закрытие соединения и отказ на закрытом порту | PASS, реальные локальные сокеты. |
| IPv6 TCP Connect | SKIP: стандартный `net.DialTimeout("tcp6", "[::1]:...", ...)` получает запрет доступа от Windows. |

IPv6-тест сначала проверяет соединение стандартной библиотекой без участия сканера. Если оно доступно, тест выполняет полноценную проверку пакета. В текущей среде реальное IPv6-подключение подтвердить нельзя; нормализация IPv6, несколько A/AAAA-адресов и правильное формирование `[IPv6]:port` проверены отдельными тестами с подменой приватного dial.

Проверены отмена подключения и DNS-запроса, ожидание общего семафора, таймаут операции и срок родительского контекста, остановка при заполненном канале, медленное чтение без потерь, общий лимит нескольких сканирований, повторное использование экземпляра, системные коды ошибок, копирование аргументов, валидация и дедупликация. Тесты не обращаются в Интернет.

Этот отчёт фиксирует локальную проверку; он не заявляет выполнение тестов на других ОС или доступность реальной внешней сети.
